# FocusFlow - User Guide

## Getting Started

Welcome to FocusFlow, your comprehensive daily planning and task management app. This guide will help you make the most of all available features.

## Main Dashboard

### Top Section: Main Widget

- **Title**: Shows app name "FocusFlow"
- **Completion Counter**: Displays completed/total actions for the month
- **Theme Toggle**: Click the ☀️/🌙 to see theme support info
- **Motivation Message**: Personalized encouragement based on your progress

### Metrics Row

Four cards showing key stats:

1. **Today** - Number of actions scheduled for today
2. **Done** - Overall completion percentage
3. **Month** - Actions completed this month
4. **Focus** - High-priority pending actions

## Features Overview

### 📋 Action Management

#### Creating Actions

1. Click the **"+ Add"** button in any section
2. Choose from **Quick Templates** for fast creation:
   - 💪 Morning stretch
   - 💼 Check emails
   - 📚 Read article
   - ✨ Family time
   - 💪 Evening walk
   - 🎯 Deep focus work
3. Or fill in manual details:
   - **Title**: Task name
   - **Category**: Choose from 6 categories
   - **Date**: Select date (YYYY-MM-DD)
   - **Time**: Set time (HH:MM)
   - **Priority**: Low, Medium, or High
   - **Notes**: Add details or targets
   - **Alarm**: Enable reminder with custom minutes

#### Editing Actions

- Click the **✎** (pencil) icon on any action
- Update details
- Click **Update** to save

#### Completing Actions

- Click the **○** (circle) or **✓** (checkmark) to toggle completion
- Completed actions move to "Completed today" section
- Actions appear with strikethrough text when done

#### Deleting Actions

- Click the **🗑** (trash) icon
- Confirm deletion
- Previous version automatically backed up

### 📊 View Modes

#### 1. Overview (Default)

- **Action Focus Panel**: Select and view specific action details
- **Monthly Trend**: Visual chart of your activity patterns
- **Category Insights**: Success rate by category
- **Achievements**: Track milestone progress
- **Action List**: All your tasks organized by completion status

#### 2. Weekly View

- **Week Navigation**: Browse previous/next weeks
- **Daily Completion**: See completion rate for each day (0-7)
- **Weekly Progress**: Visual progress bars per day
- **Streaks by Category**: Active streaks in each category

#### 3. Calendar View

- **Full Month Calendar**: Grid view of all days
- **Activity Indicators**: Colored dots show action counts
- **Today Highlight**: Current date in purple
- **Quick Navigation**: Jump to previous/next months

### 🔥 Streaks & Achievements

#### Streak System

- **Automatic Tracking**: Streaks count consecutive days of completions
- **Per Category**: Each category has its own streak
- **Fire Emoji**: 🔥 displays next to actions with active streaks
- **Weekly Display**: See all active streaks in weekly view

#### Achievement Milestones

Unlock achievements for:

- ✅ 5 completed actions
- ✅ 10 completed actions
- ✅ 25 completed actions
- ✅ 50 completed actions
- ✅ 7-day streak
- ✅ 30-day streak

Shows 🎯 when unlocked, ◯ when locked.

### 🔔 Reminders & Notifications

#### Setting Up Reminders

1. When creating/editing an action
2. Enable **Alarm** toggle
3. Set **Reminder before task** in minutes
   - 15 min before
   - 30 min before
   - 1 hour before
   - Custom minutes
4. You'll receive a notification at the scheduled time

#### Notification Details

- Shows task title
- Displays category and time
- Taps to open app (on native devices)

### 📈 Analytics & Insights

#### Monthly Trend Chart

- **Visual Bars**: Height represents action count
- **Color Coding**: Purple for active days, gray for empty
- **Date Labels**: Shows day numbers
- **Monthly Navigation**: Switch between months

#### Category Insights

- **Completion Rate**: Percentage for each category
- **Color-Coded**: Green (70%+), Yellow (40-70%), Red (<40%)
- **Completed/Total**: Shows exact counts

#### Daily Breakdown

- **Completed Today**: Quick view of finished actions
- **Upcoming**: All pending actions organized by priority

### 💾 Data Management

#### Local Storage

- **Automatic Saving**: All changes saved instantly
- **Offline Access**: Works without internet
- **No Account Required**: Data stored locally on device

#### Backup & Recovery

- **Automatic Backup**: Before each deletion
- **Last Backup**: Shows timestamp in empty state
- **Recover Previous List**: Restore before last deletion
- **Restore Sample Data**: Reset to demo actions

#### Export Data

- Click **Download** in Monthly Trend section
- Exports as CSV file with:
  - Export timestamp
  - All action details
  - Category statistics
  - Completion rates
  - Filename: `daily-planner-YYYY-MM-DD.csv`

### 📱 Today's Goals

- Click checkmark to toggle completion

## Tips & Tricks

1. **Start with Templates**: Use quick templates for common tasks

2. **Add Notes**: Include targets or sub-tasks

## Troubleshooting

### Actions Not Saving

- Check internet connection (for cloud sync features if added)
- Refresh the page
- Check browser storage permissions

### Notifications Not Working

- Ensure notifications are enabled in browser
- Check system notification settings
- Grant permission when prompted

### Data Lost

1. Check backup with "Recover previous list"
2. Restore sample data if needed
3. Export regularly to prevent data loss

### Theme Not Changing

- System theme change requires app refresh
- Check device settings for dark/light mode
